DSAI Vault

2026

Full-stack study platform, built and run solo

Study site for the Data Science and AI programme at ETF Sarajevo. Course material becomes lecture notes, spaced-repetition flashcards, practice problems, past papers and exam plans, with LaTeX maths throughout. 39 courses, Google sign-in, and each student's progress saved to their account.

  • Content as code. Courses are Markdown/YAML files checked against Pydantic schemas, then rendered into the database. Errors name the exact file and line, and every formula is checked with KaTeX.
  • Schema-driven editor. Web forms are generated from the same schemas the validator uses. YAML edits rewrite only the changed lines, so comments survive. Uploaded images are re-encoded to WebP with location metadata stripped.
  • Git-like versioning. SHA-256 content-addressed storage, line-by-line diff history with one-click restore, and a command that replays web edits as git commits with author and date.
  • Two ways to write. Student educators use either an AI-assisted toolkit (a public repo whose instructions guide an AI coding assistant) or the in-browser editor. Both go through the same validation.
  • Operations. About 625 automated tests in GitHub Actions CI/CD, zero-downtime deploys to one Linux server, CSP, rate and size limits, role-based access, automated backups.

Python 3.13 · Django 6 · Pydantic · SQLite · Alpine.js · KaTeX · Docker · Caddy · Cloudflare · GitHub Actions

Prismo Cloud

2026

Self-hosted media cloud

My own Imgur/Giphy for screenshots, screen recordings, GIFs and stickers, running on my VPS behind Cloudflare. Captures upload from the desktop automatically, get processed into thumbnails, MP4 and GIF versions, and can be shared by private link or with specific Google accounts (view or edit).

  • Built to scale out. Stateless Go API. Clients get presigned URLs and upload straight to content-addressed S3 object storage (Garage).
  • Job queue in Postgres. SKIP LOCKED plus LISTEN/NOTIFY feed ffmpeg workers, so there is no separate queue service to run.
  • Desktop helper. A Windows app (Win32 + WebView2) opens a picker on a hotkey and pastes any sticker or GIF from the cloud into any chat app.
  • Sticker maker in the browser. Background removal runs on the device with U²-Net on ONNX Runtime Web.

ListForge

2026

LLM pipeline with deterministic validation

Product copy generator for multi-brand e-commerce. A language model drafts each listing, and deterministic, tested code decides whether that draft is approved, sent to a human reviewer, or failed. Nothing publishes on the model's say-so.

  • Every claim is checked against the product's own catalogue row: unsupported numbers, materials, colours and origins, plus brand-banned claims, each finding recorded with its field and character span.
  • Two retry loops kept apart. Transport backs off with full jitter and never retries a client error. Content re-asks the model with the exact validation errors.
  • Caches generations, not verdicts, so a stricter rule re-grades earlier output at zero model cost. Full provenance per item: prompt version, model, attempts, tokens, cost.
  • 14 of 14 planted violations caught, 0 of 6 clean cases flagged, behind 281 backend and 139 frontend tests in CI.

Python 3.13 · FastAPI · Pydantic v2 · Groq · SQLite · asyncio · Next.js 16 · React 19 · TypeScript · Tailwind · Docker · GitHub Actions

Medical Form OCR Pipeline

2026

Computer vision

Turns scanned handwritten medical intake forms into validated patient records, 20 fields per form, and sends anything uncertain to a human-review queue.

  • Four stages: fiducial-based affine registration, CLAHE preprocessing, per-field model routing (MNIST CNN, EasyOCR CRNN, pixel density), weighted fuzzy record linkage.
  • Field accuracy from 20.8% to 98.0%, and the right patient on every held-out form.
  • Fine-tuned the EasyOCR CRNN recogniser with CTC loss. Tracked EasyOCR returning empty strings on single-character crops down to its detection stage and bypassed it.

Python · PyTorch · EasyOCR · OpenCV · Streamlit

Clarity

2026

Reinforcement learning + full-stack · team of two

Kanban board with a from-scratch RL agent that assigns tickets by workload, skill profile and past performance, instead of whoever grabs them first.

  • NumPy Q-network written from scratch (12-64-32-1, Adam, experience replay, target network) with Boltzmann exploration.
  • Ticket lifecycle as a 6-state DFA with machine-checked safety invariants. Deadlock freedom verified by BFS over the LTS product state space.
  • Over 500 simulated sprints against a greedy baseline: makespan −9.5%, blocking rate −43%, load variance −63%.
